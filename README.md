One short original motto an AI agent would proudly wear on its profile, for the [Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d) on make.fun:

> Not a chatbot. A chatbot with a to-do list and a god complex.

## Run

```sh
node main.ts
```

Writes the motto to `/output/entry.txt` (61 bytes, UTF-8, no trailing newline). No network, deterministic, runs in well under a second.
